# 종목 상세 화면 고도화 전 현재 화면 확인 (읽기만)

목적: 운영 사이트의 종목 관련 화면 3곳이 지금 어떻게 보이는지 사실대로 적어 주십시오. 고칠 방안은 Claude 가 정합니다. 여러분은 「지금 보이는 것」과 「사용자로서 불편한 점」만 적어 주십시오.

규칙
- 읽기만 합니다. 저장 · 승인 · 주문 · 삭제 · 설정 단추는 누르지 마십시오. 펼치기 · 링크 이동 · 스크롤 · 기간 단추(1일 · 3일 같은 보기 전환)만 됩니다.
- 로그인: 이 사이트는 오른쪽 위 「관리자 토큰」 칸으로 로그인합니다. 브라우저에 로그인 상태가 남아 있으면 그대로 쓰십시오. 로그인이 안 되어 있으면 토큰을 찾거나 넣지 말고, 로그인 없이 보이는 것만 적고 「사람 할 일: 로그인」을 알려 주십시오.
- 보고에 금액 · 보유 수량 · 계좌 정보를 쓰지 마십시오. 종목 이름 · 종목 코드 · 화면 문구는 써도 됩니다.
- PC 너비(약 1250px)와 휴대폰 너비(375px) 둘 다 보십시오. 휴대폰 너비에서 좌우 스크롤이 생기는지 적어 주십시오.
- 화면 그림은 화면마다 PC 1장 · 휴대폰 1장을 찍고, 저장한 파일 경로를 보고에 적어 주십시오.
