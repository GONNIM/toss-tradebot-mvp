## 2. 고칠 방안 (권고)

### 가. 링크 · 머리 정확도 (작음)
1. 「최근 알림」 종목 칸을 링크로. `link={false}` 9곳 가운데 줄 전체가 이미 링크 · 단추인 곳(계획 목록 · 화약고 목록)은 겹치므로 그대로 둔다(Fable ㅂ).
2. 종목 링크 모양: 밑줄 없이 강조색(틸) · 굵기 중간 · 마우스 올림 때 색 진하게(기본값 「링크 밑줄 없음」). StockLink 한 곳만 고쳐 사이트 전체에 적용.
3. 시장 표시: 국내는 저장된 krx_stock_meta.market 으로 「코스피 / 코스닥」 · 없으면 「국내」 그대로. 공개 종목 API 에는 바깥 호출을 넣지 않는다(Fable 막음 ㄱ).
4. 오래된 신호: 출처마다 갱신 주기에 맞춘 기준(매일 자료는 7일 · 주간은 21일 · 월간은 45일 등)을 넘으면 「4개월 전 자료」처럼 회색 표시. 지우지 않음(Fable ㅋ).
5. (따로 정할 일 · 가 묶음에서 뺌) 토스 링크는 1025-06 에 「주문 화면이 열림」으로 승인된 목표다. 종목 화면으로 바꿀지는 사용자 결정 ㉡ 으로 올린다(Fable 막음 ㄷ).

### 나. 국내 종목 가격 · 전문가 의견 칸 (중간)
- 새 API `GET /api/v1/stock/{code}/quote` (관리자만 · 국내 6자리 코드만 · 코드는 krx_stock_meta 또는 DART 회사 목록 가운데 종목코드가 있는 행만 → 아무 글자나 바깥 호출하지 않음 · 비로그인 요청과 목록 밖 코드는 네이버 호출 0 을 시험으로 막음 · Fable ㅁ ㅊ).
- 자료: 네이버 일봉(시가 · 고가 · 저가 · 종가 · 거래량 · 5년 가능 여부는 구현 첫날 확인 · 안 되면 받을 수 있는 만큼) + 종합 API(현재가 · 시총 · 52주 · 외국인 비율 · 의견). 새 표 kr_quote_daily 에 저장(바이오 표는 30일 정리가 지우므로 쓰지 않음) · 같은 종목 10분 캐시 · 하루 바깥 호출 상한 300번(종목 약 150개). 수정주가 여부를 모르므로 그림 출처 문장에 「네이버 일봉 · 수정주가 여부 확인 전」을 적는다(Fable ㅁ ㅈ).
- 칸 순서는 /biotech 와 같게: 현재가 → 그림(일봉/40주) → 숫자 칸(종가 · 거래량 · 평균 거래량 · 시총 · 52주 범위 · 외국인 비율) → 전문가 의견(평균 의견 · 평균 목표가 · 작성일 · 출처 · 「추정 · 보장 아님」을 같은 칸에 · 없으면 「증권사 의견 없음」 · 리포트 제목 목록은 1차에서 뺌) → 출처(Fable 막음 ㄹ).
- 미국은 지금처럼 바이오 후보만(Fable 막음 4 유지) · 후보가 아니면 지금 문구.
- AI 요약은 이번에 넣지 않음(비용 · 별도 판단).
- 로그인 안 한 사람: 지금처럼 「로그인하면 보입니다」 + 그 까닭.

### 다. 거래량 막대 (중간)
- 그림 점에 거래량 `v` 를 더함: 미국 야후 일봉 저장 때 Volume 도 저장(biotech_long_close 에 칸 추가 · 운영 표에 생기도록 db.py 추가 칸 목록에 넣음 · 칸을 더한 뒤 한 번 긴 기간으로 다시 받아 옛 날도 채움) · 국내 네이버 일봉은 처음부터 있음. 주봉은 그 주 합계(Fable ㅅ).
- MaChart 아래에 따로 둔 작은 그림(가격 그림 높이의 약 25% · 같은 날짜 축)에 막대 · 오른 날 빨강 · 내린 날 파랑(한국식) · 막대 위 숫자 없음 · 마우스 올림 칸에 거래량(Fable ㅇ).
- MaChart 에 「거래량 보이기」 속성을 두고 기본은 끔. 종목 상세 · /biotech 펼침만 켬. 계획 화면은 같은 API 를 읽지만 속성이 꺼져 있어 지금과 같음(Fable 막음 ㄴ).
