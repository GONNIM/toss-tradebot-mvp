# 1119-02 종목명과 종목코드 함께 표시 — 기획

- 등록: 2026-11-19 · 사용자 지시: 「한국주식은 종목명(종목코드) 같이 표기 … 미국주식은 종목코드 하단에 종목명(회사명) … 각각만 표시되는 경우 같이 병기」 · 계획 요약 승인 · ㉥ 텔레그램 알림도 같은 규칙 (11/19)
- 공개 저장소: 실제 종목명 · 코드를 문서 · 시험에 쓰지 않는다 (예시 「테스트전자(000000)」 · TESTA).
- 순서: 1119-01(PR #228) 병합 뒤 시작 (종목 화면 파일 겹침). 단일 배포.

## 1. 표시 규칙
| 시장 | 이름 있음 | 이름 없음 |
|---|---|---|
| 한국 | `테스트전자(000000)` 한 줄 (좁은 칸은 줄바꿈해도 괄호 모양 유지) | `000000 (종목명 확인 안 됨)` |
| 미국 | 티커(굵게) · 아래 줄 회사명(작게) | 티커만 |
- 링크가 있던 곳은 링크 유지 (`/stock/코드`).
- 이미 규칙을 지키는 곳은 바꾸지 않는다 (예: 대장주 분석 패널).

## 2. 공용 부품
- `frontend/components/stock/StockLabel.tsx` 새로: props `code` · `name?` · `market?`(없으면 6자리 숫자면 KR) · `link?` · `layout?`(inline / stacked). 안에서 `StockLink` 재사용.
- `StockLink` 는 그대로 두고 표시는 StockLabel 로 통일.

## 3. 서버 — 응답에 이름이 없는 곳 (약 14곳)
- 한꺼번에 찾기: `backend/services/stock_names.py` 에 `lookup_kr_names(codes) -> dict` (출처 순서는 기존 `lookup_kr_name` 과 같음: KrxMarketSnapshot → LiveTapeUniverse → PowderKegList → KrxStockMeta · 표마다 IN 조회 1번) · 미국 `lookup_us_names(tickers)` (TickerUniverse.company_name → MemeUniverse.name).
- 붙일 응답: 홈 판단 기한 · 보유 경보 · 판단 일지(목록 · 상세 · 모달) · 토스 코드 표 · 스나이퍼 신호 이력 · 화약고 이벤트 · 시장 목록 · 관심 목록 신호 · 밈 결과 표 · 우량주 무효화 이력 · 원칙 게이트 · 본문 · 계획 목록 · 상세 (구현 첫 단계에서 화면별 파일:줄 대조표를 다시 만든다).
- 응답 모델에 `name: Optional[str]` 추가 · 기존 키는 바꾸지 않음.

## 4. 화면 — 약 31곳을 StockLabel 로
- 조사 표(11/19)의 파일:줄 전부. 구현 첫 단계에서 `grep` 으로 빠진 곳을 다시 찾는다(`.ticker}` · `.symbol}` · `.code}`).

## 5. 텔레그램 (㉥ · 약 5곳)
- `alert_text.stock(name, code)` 규칙으로 맞춤: `discovery/live_tape/exit.py:112` · `execution/plan/drafts.py:305·307` · `services/notifier.py:401`(이름만 → 코드 병기) · `notifier.py:337·361`(미국 후보 · 회사명 병기) · `execution/plan/engine.py` 알림 종목 표기.
- 알림 문장 규칙(명령문 · 신호 낱말 금지)은 그대로.

## 6. 실패 · 빈 경우
| 경우 | 동작 |
|---|---|
| 한국 이름 못 찾음 | `000000 (종목명 확인 안 됨)` |
| 미국 이름 못 찾음 | 티커만 |
| 이름 조회 DB 오류 · 잠금 · 시간 초과 | 이름 없이 응답 200 · 로그 1줄 (목록 전체가 실패하지 않음) |
| 시장 정보 없음 | 6자리 숫자면 한국 · 아니면 미국 |
| 코드 모양이 아님 | 받은 글자 그대로 · 링크 없음 (StockLink 기존 동작) |
| 목록이 김 (수백 행) | 표마다 IN 조회 1번 · 행마다 조회 금지 |
| 이름에 괄호 · 특수문자 | 그대로 표시 (HTML 이스케이프는 React 기본) |
| 텔레그램 이름 없음 | `000000 (종목명 확인 안 됨)` (alert_text 기존 규칙) |

## 7. 시험
- `lookup_kr_names` · `lookup_us_names`: 출처 순서 · 못 찾음 · DB 예외 · 조회 횟수(표마다 1번).
- 붙인 응답마다 `name` 키 · 이름 없음 시험.
- StockLabel 표시 규칙: tsc + 화면 렌더(1280 · 380) 대표 화면 5곳 이상.
- 텔레그램 문장 시험 5곳.

## 8. 버전 · 배포
- 서버 `backend/api/main.py` · 화면 `frontend/package.json` 둘 다 올림 · 새 표 · 열 없음.
- 기획서 → Fable → 구현(작업 폴더) → 검토 → Fable 병합 승인 → 사용자 병합.
