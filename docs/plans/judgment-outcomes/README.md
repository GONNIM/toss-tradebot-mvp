## 가격 소스 (Fable 막음 1)
- 기준가(T0)와 결과가(T+N) 모두 토스 일봉 (GET /api/v1/candles 1d · adjusted 기본) — 같은 소스로 양끝.
- 토스에 없는 종목·봉이 없으면 「계산 불가」(칸 비움 + 이유 기록) · 다른 소스로 채우지 않음.
- 서버 cron 에서만 호출 · 로컬은 테스트 더블.

## 계산식 (Fable 막음 2)
- T0 = 판정·후보가 나온 시각에 이미 있던 마지막 일봉 종가 (현지 거래일 기준).
  예: Crazy 06:30 KST (10/25) = 미국 10/24 종가. 국내 판정 10:00 KST = 전 거래일 종가.
  저널 판정은 entry_price 가 있으면 그 값을 기준가로 · 없으면 위 T0.
- 수익률 = T+N 종가 / 기준가 − 1.
- 손절가 도달: 저널 판정에 invalidation_price 가 있으면, T0 다음 날부터 T+N 까지 일봉 저가가 손절가 이하인 첫 날을 invalidation_hit_ts · 그 저가를 _low 로 (공매도형: 목표<진입<손절 이면 고가 ≥ 손절).
- 대체된 판정 (superseded) 은 계산하지 않음 · 청산 행 (page_source=close · horizon 1) 도 제외 · 전환 (transition) 행은 새 판정이라 계산.
- 기준 시각 = created_at / ts (UTC) 를 현지 시간대로 (pick_date 안 씀). 현지 정규장 마감 (KR 15:30 · US 16:00 ET) 뒤면 그날 봉, 앞이면 전 거래일 봉.
- T+N = T0 날짜 + N 달력일과 같거나 뒤인 첫 거래일 봉 (Moonshot = T0 뒤 N번째 봉). 손절·최고가는 저가·고가 파서 따로.
