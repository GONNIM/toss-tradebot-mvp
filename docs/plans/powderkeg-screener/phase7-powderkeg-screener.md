# Phase 7 — 화약고 스크리너 (Powder Keg Screener) 작업 지시서

너는 이 리포지토리(toss-tradebot-mvp)의 시니어 퀀트 엔지니어다.
아래 지시에 따라 신규 모듈 "화약고 스크리너"를 구축하라.
전략 정의: **딥밸류(그레이엄 net-net + 피오트로스키 필터) × 지배구조 카탈리스트(그린블라트 특수상황)**.
"현금 많고 싸고 오너 지분이 높은데 오너에게 현금이 필요해지는 사건이 발생한 종목"을 탐지한다.

**전제 조건: Phase 0(백테스트 인프라)이 완료되어 있어야 한다. 미완료 시 Phase 0부터 수행하라.**

**전역 원칙 (Phase 0~6과 동일):**
- 모든 시그널은 백테스트 검증 전까지 `hypothesis` 상태. 자동매매 연결 금지.
- as-of(공시 접수일시 기준) 정렬, 거래비용 반영, in/out-of-sample 분리 강제.
- 이 모듈의 출력은 "매수 추천"이 아니라 "관찰 후보 + 이벤트 알림"이다. UI 전반에 투자 권유 아님 고지를 표시한다.

## 7-1. 데이터 파이프라인

### 작업
1. **DART OpenAPI 수집기** (`backend/powderkeg/collectors/dart.py`):
   - 전체 상장사 최근 사업/반기/분기보고서에서: 재무상태표(현금및현금성자산, 단기금융상품, 총차입금, 자본총계, 이익잉여금), 손익계산서(영업이익, 당기순이익, 이자수익), 감사의견.
   - 최대주주 및 특수관계인 지분율 (주식등의대량보유상황 + 사업보고서 '최대주주 현황').
   - 자기주식 보유 현황.
   - 모든 레코드에 `reference_date`(보고 대상 기간)와 `release_date`(공시 접수일시)를 분리 저장 (Phase 0 asof 규약 준수).
2. **KRX 수집기**: 시가총액, PBR, 상장시장 구분, 거래대금(유동성 필터용).
3. **공정거래위원회 공시대상기업집단 명단** 수집기 (연 1회 갱신): 대기업집단 소속 여부 플래그.
4. **뉴스/공시 이벤트 수집기** (`collectors/events.py`):
   - DART 공시 제목 키워드 폴링(기존 Activist Radar의 DART 폴러 재사용/확장): "횡령·배임 혐의발생", "최대주주 변경", "주식담보제공 계약", "상속", "임원 변경(대표이사 사임)", "소송 등의 제기", "배당", "자기주식 취득/소각", "주식등의 대량보유상황(경영권 영향)", "기업가치 제고 계획".
   - 뉴스 크롤링(선택): 화약고 리스트 종목명 + {"구속", "기소", "검찰", "압수수색", "별세", "상속"} 키워드 매칭. 뉴스 소스와 수집 주기는 config로 관리.

### 완료 기준
- [ ] 전 상장사 재무 스냅샷이 DB에 적재되고 release_date가 기록된다.
- [ ] 수집 실패/스키마 변경 시 알림이 발생한다.

## 7-2. 정적 스크린 (화약고 리스트)

### 작업
`backend/powderkeg/screener.py` — 분기 1회 + 수동 트리거로 실행. 아래 조건을 모두 만족하는 종목을 `powder_keg_list`에 적재:

| # | 조건 | 기본값 (config로 조정 가능) |
|---|------|------|
| 1 | PBR | < 0.5 |
| 2 | 순현금(현금성+단기금융상품 − 총차입금) / 시가총액 | > 40% |
| 3 | 최대주주+특수관계인 지분율 | ≥ 40% |
| 4 | 공정위 공시대상기업집단 소속 | 아님 |
| 5 | 감사의견 | 적정 (최근 2개 연도) |
| 6 | 이자수익 교차검증: 이자수익 / 평균 현금성자산 | ≥ (기준금리 − 1.5%p) — 미달 시 `cash_suspect` 플래그 후 제외 |
| 7 | 영업이익 | 최근 3년 중 2년 이상 흑자 |
| 8 | 피오트로스키 F-Score | ≥ 6 (9개 항목 계산기 구현 포함) |
| 9 | 일평균 거래대금(60일) | ≥ 1억원 (유동성 최소선) |
| 10 | 관리종목/거래정지/감사의견 비적정 이력(3년 내) | 없음 |

- 각 종목에 서브스코어 저장: 순현금비율, F-Score, 지분율, 배당성향, 자사주 비율.
- 조건 6은 별도 함수 `verify_cash_reality()`로 분리하고 단위 테스트 작성 (분식 탐지 핵심 로직).

### 완료 기준
- [ ] 스크린 실행 시 화약고 리스트가 생성되고 각 조건별 통과/탈락 사유가 기록된다.
- [ ] F-Score 계산기가 알려진 예제 재무제표로 검증된다.

## 7-3. 이벤트 트리거 엔진 (불꽃 감지)

### 작업
`backend/powderkeg/triggers.py` — 화약고 리스트 종목에 한해 이벤트를 분류:

**타입 A — 매수 후보 트리거 (오너에게 현금이 필요해지는 사건):**
- A1: 최대주주 개인 사법 리스크 뉴스/공시 (회사 자금과 무관한 건: 개인 비리, 폭행, 개인 소송 등)
- A2: 최대주주 사망·상속 관련 공시
- A3: 최대주주 주식담보제공 계약 공시 (현금 수요 신호)
- A4: 행동주의 펀드의 신규 5% 보고 (보유목적 '경영권 영향') — 기존 Activist Radar KR 트랙과 연동
- A5: 배당 확대·자사주 소각·기업가치 제고 계획 첫 공시 (카탈리스트 발화 확인)
- A6: 상법 개정 관련 압박 이벤트: 저PBR 명단 공표(2026.11 첫 공표 예정) 포함 여부, 자사주 소각 시한 도래

**타입 B — 즉시 제외 트리거 (현금이 가짜였거나 사라지는 사건):**
- B1: "횡령·배임 혐의발생" 공시 → 화약고 리스트에서 즉시 제거 + `do_not_touch` 라벨 + 보유 중이면 최우선 알림
- B2: 감사의견 비적정/한정, 감사보고서 제출 지연 공시
- B3: 거래정지, 상장적격성 실질심사 대상 지정

**분류 규칙:**
- 뉴스 기반 A1 분류는 키워드 매칭 + (가능 시) LLM 분류기(Anthropic API)로 "회사 자금 관련 여부"를 판별. LLM 판별 결과는 confidence와 근거 문장을 함께 저장하고, confidence < 0.8이면 `needs_human_review` 상태로 알림만 발송.
- 타입 A와 B가 동시 발생하면 B가 무조건 우선한다.

### 완료 기준
- [ ] 타입 B 공시 발생 시 리스트 제거 + 알림이 5분 내 발생한다 (기존 DART 폴러 주기 재사용).
- [ ] A/B 분류 로직에 대한 단위 테스트 (모의 공시 제목 20건 이상).

## 7-4. 백테스트 (실탄 투입 전 필수 게이트)

### 작업
1. 과거 5년(최소 3년) DART 공시/뉴스 아카이브에서 타입 A 이벤트를 수집해 이벤트 데이터셋 구축 (이벤트 수집 자체의 look-ahead 주의: 뉴스 발생일시 기준).
2. Phase 0 엔진으로 이벤트 스터디: 이벤트 후 t+1일 시가 진입 가정 → 1/3/6/12개월 CAR, 승률, MDD. 화약고 조건 충족 종목 vs 미충족 종목으로 층화해 "화약고 조건이 실제로 수익률을 가르는가"를 검증.
3. 타입 B 이벤트도 동일 측정해 "즉시 제외" 규칙의 손실 회피 효과를 정량화.
4. 결과가 음수여도 리포트에 그대로 게시. 비용 차감 후 t-stat > 2 + 표본 ≥ 50건 통과 시에만 트리거를 `validated`로 승격.

### 완료 기준
- [ ] 이벤트 타입별 CAR 리포트 생성.
- [ ] validated 승격 게이트가 코드로 강제된다.

## 7-5. 포트폴리오·운영 규칙

### 작업
1. `validated` 트리거에 한해 반자동 주문 티켓(1클릭 승인) 생성 — Phase 1과 동일 패턴 재사용.
2. 공용 리스크 모듈(Phase 2에서 추출) 연동:
   - 동시 보유 10~15종목 분산 강제, 종목당 자본의 5% 상한.
   - 진입 시 무효화 조건 필수 입력: (a) 가격 무효화(예: 진입가 −15% 또는 스윙 저점 이탈), (b) 논리 무효화(무혐의 확정, 지분 방어 성공, 타입 B 발생 등 카탈리스트 소멸) — 발생 시 기계적 청산 알림.
   - 보유 기간 상한(기본 12개월) 경과 시 재평가 알림.
3. VIP 감시(Phase 5)와 연동: 화약고 보유 종목은 자동으로 VIP 감시 등록.

### 완료 기준
- [ ] 무효화 조건 미입력 시 주문 티켓이 생성되지 않는다.
- [ ] 종목당/전체 한도 초과 시 차단된다.

## 7-6. UI

### 작업
1. 신규 메뉴 "🧨 화약고 스크리너":
   - 탭 1 화약고 리스트: 종목별 서브스코어(순현금/시총, F-Score, 지분율, PBR, 자사주 비율) 테이블 + 조건별 통과 뱃지.
   - 탭 2 불꽃 피드: 타입 A/B 이벤트 타임라인 (A는 주황, B는 빨강 + DO NOT TOUCH 표기).
   - 탭 3 백테스트 리포트: 이벤트 타입별 CAR 곡선, validated/hypothesis 상태 표기.
2. 모든 화면 하단 고지: "본 화면은 공시·재무 데이터 기반 관찰 후보이며 투자 권유가 아닙니다. 오너 관련 이벤트 표기는 공시·언론 보도 사실의 인용입니다."
3. 오너 개인 사건 표기는 공시/기사 원문 링크만 제공하고 모듈 자체 판단 문구(예: "엉망", "범죄자")를 표시하지 않는다 — 명예훼손 리스크 방지.

### 완료 기준
- [ ] 세 탭이 렌더링되고 이벤트 색상 구분이 동작한다.
- [ ] 고지 문구가 전 화면에 표시된다.

## 작업 방식 지시
- 기존 Activist Radar의 DART 폴러, Phase 0 백테스트 엔진, Phase 2 리스크 모듈을 최대한 재사용하라. 중복 구현 금지.
- Phase 7 전용 브랜치에서 작업하고 7-1부터 순서대로 커밋하라. 각 커밋에 완료 기준 체크 결과를 포함하라.
- DART OpenAPI 키, 뉴스 소스, 스크린 임계값은 전부 config로 외부화하라.
- 백테스트 결과가 기대와 다르면(CAR 음수 등) 숨기지 말고 게시하라. 이 모듈의 1차 목표는 매수 리스트가 아니라 "화약고+불꽃 가설의 기대값을 숫자로 확인"하는 것이다.
