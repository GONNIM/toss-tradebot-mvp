## 2. 서버

### 2.1 GET /api/v1/account/vip
- 인증: require_sniper_token (없으면 401). 1110-01 과 같은 방식.
- 외부 호출: 토스 보유 조회 1번만. 나머지는 DB.
- 목록 규칙 (㉢②):
  1. 가장 최근 하루 1회 보유 기록에서 비용 반영 손익(`net_pnl_pct` · 매도 비용 뺀 값 · 1108-02 계획 3절 「비용 반영 실질 평단 기준」과 같은 계산) < 0 인 종목 → `reason="loss"`. 비용 전 +0.1% · 비용 후 −0.1% 는 손실로 넣음.
  2. 비용 반영 손익이 0 이상이지만 `profit_turn`(흑자 전환 계산 · 하루 1회 기록 기준)의 `rows_since` ≤ 5 → `reason="turned"` · `turn_date` 함께. `profit_turn` 은 지금 단기 종목만 계산하므로, 보유 성격과 상관없이 같은 함수(qty≤0 이면 연속 초기화 포함)를 불러 계산한다. 「5거래일」은 기록 행 5개라 기록 잡이 빠진 날만큼 길어진다(한계 한 줄).
  3. 설정 종목(VIP_TICKER 의 점 앞 기호 = 토스 미국 기호) → `is_vip_config=true`. 보유 없음이면 `reason="config_only"` · 포지션 칸 null.
  4. 오늘 산 종목처럼 보유 기록이 아직 없는 종목은 넣지 않는다(다음 기록 국내 15:50 · 미국 07:10 뒤 들어감). 응답 `limits` 에 한 줄.
  5. 보유 기록에는 있으나 토스 실시간 응답에 없는 종목(오늘 판 종목)은 탭에서 뺀다. 응답 `limits` 에 「오늘 판 종목은 탭에서 뺐습니다」 한 줄. 단 설정 종목이면 3 번 규칙(`config_only`)을 따른다.
  6. 설정 종목 매칭은 `backend/discovery/vip/config.py` `_derive_tag`(점 앞 · 대문자)를 재사용하고 토스 기호도 대문자로 바꿔 비교한다.
- 종목마다: `market, symbol, name, reason, turn_date|null, is_vip_config, position{avg_price, qty, current_price, pnl, pnl_pct, source:"toss"}|null, chart, goal|null, ma_text`.
  - `position` 은 토스 실시간 값 그대로(재계산 금지 · 원장 기준).
  - `goal` 은 보유 성격이 정해진 종목만(1108-02 3단계 계산 재사용). 미지정이면 null + 「보유 성격을 정하면 목표 칸이 보입니다」. `goal` 이 있으면 `disclaimer: "추정 · 보장 아님"`(DISCLAIMER 상수)을 함께 보낸다.
- 순서: 설정 종목 → 손실 % 큰 순 → 흑자 전환 종목.

### 2.2 그림 자료 `chart` (계좌 카드 `/account/swing` 에도 같은 모양으로 넣음)
- `daily`: 최근 1년 일봉 `[{d, c, m20|null, m50|null, m200|null}]`. 200일선을 1년 내내 그리려면 약 450거래일 필요 → 긴 일봉 표(swing_long_close · 국내 pykrx 수정주가 2000~ · 미국 yfinance 배당 미조정 10년). 모자라면 그 점만 null(1년 창 앞쪽만 null 인 경우 포함) · `note="자료 부족"` 은 마지막 날 값이 null 일 때만.
- `daily_source`: 긴 일봉 출처 이름 + 기간.
- `week40`: PR #193 의 필드 그대로(주봉 5년 · 검증 줄 · 사실 줄).
- 미지정 종목도 `chart` 를 채운다(㉣② · PR #193 시험 ⑧ 「미지정이면 week40 없음」을 뒤집음).

### 2.3 카드 글자 줄 200일 (이평 ㉡②)
- MA_DAYS (20, 60, 120) 은 그대로(60일 = 1108-02 규칙 입력 · 계획 3절). 200일 거리 줄을 따로 더한다.
- 200일 값은 긴 일봉에서 계산 → 줄 옆 출처 글자를 따로(「KRX 일봉(pykrx · 수정주가)」 · 「Yahoo 종가(yfinance · 배당 미조정)」). 20·60·120 줄 출처(국내 KRX 공식 종가 · 미국 토스 일봉)는 그대로.
- 긴 일봉 200개 미만이면 「200일 자료 부족」.

## 3. 화면

### 3.1 /vip
- 로그인 안 됨(401) → 「로그인 필요」(1110-01 부품).
- 맨 위 탭: 「종목명(종목코드) · 손익%」. 흑자 전환 탭은 「흑자 전환 MM/DD」 · 설정 종목만이면 「보유 없음 · 설정만」. 고른 탭은 주소 `?t=<market>:<symbol>` 에 남김. `?t=` 값이 목록에 없으면 첫 탭을 연다.
- 탭 안 순서: ① 포지션(「토스 원장」 글자) ② 평균선 그림 ③ 목표까지 거리 ④ (설정 종목 탭만) 기존 시세 통계 · 알림 조건 · 알림 기록 · activist 칸 — 여기 손익은 「설정 평단」 글자.
- 새로 고침: 계좌 조회 60초. 30초 미국 시세 조회는 설정 종목 탭을 열었을 때만.
- 적자 종목 0개 + 설정 종목 없음 → 「지금 적자인 종목이 없습니다」.

### 3.2 그림 부품 (계좌 카드 · VIP 탭 공용)
- 단추 두 개: 「일봉 1년 · 20·50·200일」(기본) / 「주봉 5년 · 40주」(PR #193 Week40Chart).
- 일봉 선: 종가 · 20일 · 50일 · 200일 (≈40주). 선 이름은 범례와 선 끝 글자로(색만으로 구별하지 않음). 숫자는 tabular-nums. 상승 빨강 · 하락 파랑과 겹치지 않는 색.
- 선 상태 문장 없음(「50일선이 200일선 위」 같은 줄 쓰지 않음).
- 검증 줄은 주봉 화면의 「40주선(≈200일선) · 주봉 기준 검증」 하나. 공통 한계 줄에 「20·50일선 규칙도 미통과(2026-11-10 · 공개 시세 145종목)」를 더함.
- 일봉 화면 아래 출처 줄: 긴 일봉 출처 · 기간 · 「그림 평균선과 카드 글자 줄은 출처가 달라 값이 조금 다를 수 있음」 · 「사실 표시이며 매매 지시가 아님」.
