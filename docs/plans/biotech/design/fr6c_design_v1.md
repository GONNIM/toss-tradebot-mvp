  | 09:30 전 | 직전 거래일 종가 | 당일 종가 |

- 반응일 초과 수익률 = (종목 반응가 ÷ 종목 기준가 − 1) − (XBI 반응가 ÷ XBI 기준가 − 1).
- 화면 이름: "반응일(0~+1거래일) XBI 대비 초과 수익률".
- 칸마다 표시하는 값: n · 중앙값 · 사분위 (25 · 75) · 최솟값 · 최댓값 · 기간 (가장 이른 발표일 ~ 가장 늦은 발표일) · 방향 출처 비율.
- 평균은 표시하지 않는다.
- 가격 없는 건 (세부 규칙 b · 19절 답 7): 종목 기준가 · 종목 반응가 · XBI 기준가 · XBI 반응가 중 하나라도 없으면 그 칸의 n 에 넣지 않는다. 대신 "가격 없음 k건" 을 함께 적는다.

### 3.1 사분위 · 중앙값 계산 (19절 답 3)

- 방법: 선형 보간 (numpy `percentile` 기본값 `method="linear"` · R type 7 · Excel PERCENTILE.INC 와 같음).
- 식: 값을 작은 것부터 x₀ ≤ x₁ ≤ … ≤ x₍ₙ₋₁₎ 로 놓는다. p 분위의 위치 h = (n − 1) × p 이다. j = ⌊h⌋ · g = h − j 일 때 Q(p) = x_j + g × (x₍ⱼ₊₁₎ − x_j) 이다 (h 가 정수면 Q(p) = x_h).
- 중앙값 = Q(0.5). n 이 짝수면 가운데 두 값의 평균이다.
- 최솟값 = Q(0) = x₀ · 최댓값 = Q(1) = x₍ₙ₋₁₎.
- 예시 (n = 6 · 초과 수익률 −0.10 · −0.04 · 0.00 · 0.02 · 0.06 · 0.30):
  - 25%: h = 5 × 0.25 = 1.25 → −0.04 + 0.25 × (0.00 − (−0.04)) = −0.03
  - 중앙값: h = 2.5 → 0.00 + 0.5 × (0.02 − 0.00) = 0.01 (가운데 두 값 0.00 · 0.02 의 평균)
  - 75%: h = 3.75 → 0.02 + 0.75 × (0.06 − 0.02) = 0.05
  - 확인: numpy 2.5.0 `np.percentile([-0.10, -0.04, 0.00, 0.02, 0.06, 0.30], [0, 25, 50, 75, 100])` → [−0.10, −0.03, 0.01, 0.05, 0.30]

## 4. 칸 축과 표시 규칙

- 세밀도 순서 (거친 것 → 세밀한 것): 전체 (방향 무관) → 방향 → 방향 × 단계 → 방향 × 단계 × 시총 (결정 5).
- 표시 기준: n 이 20건 이상인 칸만 숫자를 보여 준다. 20건 미만 칸은 "표본 부족(n건)" 으로 숫자 없이 적는다 (PRD FR-6c · 결정 5).
- 잔여 칸 (19절 답 1 · 5): 단계 축의 "단계 미확인" · "4상" · "초기 1상" (EARLY_PHASE1) · "NA" 와 시총 축의 "시총 없음" 은 잔여 칸이다. 잔여 칸은 n 이 20 이상이어도 행으로 보여 주지 않는다. 잔여 칸의 건은 거친 칸 (전체 · 방향) 에만 들어간다. 잔여 칸은 사용자에게 뜻이 없기 때문이다.
- 거친 칸은 지금 보여 주고, 세밀한 칸은 표본이 차는 대로 열린다.
- 상세 화면 (세부 규칙 a · 19절 답 7): 그 종목의 조건 (발표 예정 임상의 단계 · 현재 시총 구간) 에 맞는 칸 가운데, 20건 이상이고 잔여 칸이 아닌 가장 세밀한 칸을 쓴다. 발표 전이므로 세 방향 칸 (긍정 · 혼재 · 부정) 을 나란히 보여 준다. 20건 미만 방향은 "표본 부족(n건)" 이다.
- 각 행에 칸의 세밀도 · n · 기간 · 방향 출처 비율을 적는다.
- 재판정 (19절 답 4): 칸 세밀도는 매월 1일 KST 07:00 일일 파이프의 끝에서 다시 판정한다. 그날이 비거래일이어도 날짜 기준으로 한다.
- 오늘 기준으로 보일 행은 부록 B 에 있다.
