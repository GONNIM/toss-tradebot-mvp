## 3. 통계 · 백테스트 용어

| 코드 | 뜻 |
|---|---|
| **CI (신뢰구간)** | 95% 확률로 참값이 이 안에 있음 · [하한, 상한] |
| **CI 하한 > 0** | 신뢰구간 하한이 양수 = 알파 존재 확정 |
| **CI 상한 ≤ 0** | 신뢰구간 상한이 음수 = 음의 값 확정 |
| **mean net excess** | 평균 순초과수익 (종목 수익 - 벤치 수익 - 비용) |
| **bootstrap** | 표본 재추출로 신뢰구간 계산 (10,000회 · seed 42) |
| **date-cluster / 클러스터** | 같은 날짜 이벤트를 통째로 재추출 (일반 재추출보다 보수적) |
| **alpha_pass** | 알파 통과 = mean ≥ 임계 AND CI 하한 > 0 AND hit ≥ 35% |
| **deprecation_triggered** | 폐기 발동 = 알파 없음 확정 · 재도전은 사전 등록 필수 |
| **hit_rate** | 히트율 = 양의 수익 비율 |
| **shortened** | 창 단축 = 인수·폐지로 목표일 이전 종료 |
| **look-ahead** | 미래 데이터 미리 보기 (금지) |
| **point-in-time** | 그 시점에만 알려진 정보만 사용 |
