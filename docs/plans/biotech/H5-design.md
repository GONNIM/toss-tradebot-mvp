## 1. 정의 (README §2 H5 승계)

**해외 (주로 FDA/EMA) 촉매 이벤트일 D-day 기준 국내 (KOSDAQ150 바이오 서브셋) 연계 종목의 초과수익**을 측정한다. 국내 자체 촉매 (KR 임상·KR IND) 는 KR-TRACK 의 **H1-KR** (별도 트랙) 로 분리.

## 2. 연계 유형 4분류 (사전 커밋 · 사후 조정 금지 · v2.1 세분화)

| # | 유형 | 매핑 소스 (사전 커밋 · v2.1) | 예시 (사후 룰 통과 사례만) |

**v2.1 DART 필터 세부 (사전 커밋)**:
- **공시유형**: 주로 `pblntf_ty=B` (주요사항보고서) 사용 · `pblntf_ty=I` (거래소공시 · 조회공시) 는 H8 채널 7 로 분리 · `pblntf_ty=A` (정기공시) 는 유형 3 파이프라인 파싱에만 사용
- **대상 범위**: **KOSPI + KOSDAQ 제약바이오 업종 전체** · KRX 업종 코드 (KOSDAQ 271010 제약 · 275010 의료정밀 등 · KOSPI 유가 021 의약품) 로 corp_code 사전 필터
- **시장별 벤치마크 분리 (v2.1 · 사후 조정 금지)**:
  - KOSPI 종목 → **KOSPI200**
  - KOSDAQ 종목 → **KOSDAQ150**
  - 시장 혼재 pooled 통계 금지 (버킷별 별도 산출)

**매핑 원칙 (사전 커밋)**:
- 룰만 사전 정의 · 사후 사건 인입 금지 (H2 규약 승계)
- 매핑 부재 종목은 H5 이벤트 제외 (연계 부재)
- 다중 유형 매치 시 우선순위: License-in/out > 직접 매출 > Class effect > CDMO

## 3. 창·benchmark·비용 (사전 커밋)

- **창 (3구간 별도 산출)**:
  - **D-5 ~ D-1** (사전 · 소문/기대)
  - **D+1 ~ D+5** (즉시 · 반응)
  - **D+1 ~ D+20** (지속 · 확산)
- **benchmark**: **KOSDAQ150** (US 트랙 XBI/IWM 아님)
- **비용**: 왕복 **0.5%** (KR 소형주 스프레드 반영 · US 1.0% 와 별도)
- **진입가**: D+1 종가 (adj_close · look-ahead 배제)
- **판정식**: bootstrap 10,000회 · seed 42 · 95% CI (§2-0 승계)

## 4. 알파 임계 (사전 커밋 · 사후 조정 금지)

- **D-5~D-1 (사전)**: net excess ≥ **+2%** · CI 하한 > 0
- **D+1~D+5 (즉시)**: net excess ≥ **+3%** · CI 하한 > 0
- **D+1~D+20 (지속)**: net excess ≥ **+5%** · CI 하한 > 0
- **부호 검증 (B8 대립가설)**: KR 바이오 "호재 공시 당일 매도" 관측 → 각 구간 net excess 부호 자체가 결과 · **부호와 무관하게 CI 하한 절대값** 검증 (매도 방향 알파도 유효)

## 5. 폐기 조건

- 3구간 모두 bootstrap 95% CI 하한 ≤ 0
- OR 연계 유형 매핑 없이 사후 추가 (룰 위반)
- OR 유형 4분류 사후 조정

## 6. B8 대립가설 (KR 이식 금지 조항 승계)

**관측 근거**: 2026-08 TikTok @guess8282 (2026-08-27 · **인플루언서 1인 의견 · 사실 판정 아님**) — "KR 바이오는 호재 공시 당일 매도 패턴".

**H5 반영**:

## 8. H8 국내 채널 이관 (B128)

**조회공시 절**: 이전 초안 §2-1·§2-2 (조회공시 = 소문 층) 는 **H8-design §2 채널 7 (DART 조회공시)** 로 이관. H5 는 조회공시를 **소문 지수 원천으로 참조만** 하며 H5 이벤트 D-day 자체가 조회공시가 아님 (D-day = 해외 촉매 발표일).

**H5 이벤트가 H8 이벤트 풀에 편입 시**:
- 소문 지수 산정 시 KR 채널 (DART 조회공시) 우선 결합
- US 채널 (AACT · bioRxiv · PubMed · 연방관보) 병행 여부 별도 판정
- 채널 ≥2 유효 조건은 KR/US 혼용 허용
