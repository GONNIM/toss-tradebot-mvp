## 1. H8 정의 (v2)

**지수 창** = **D-180 ~ D-31** (검정 1 수익 창 D-30~D-1 과 배타 · 미래 참조 배제)
**기준선 창** = **D-360 ~ D-181** (티커별 정규화 기준)

**소문 지수** (사전 커밋 · 사후 조정 금지):
```
index(ticker, D) = (신호수[D-180 ~ D-31] - 신호수[D-360 ~ D-181])
                 / max(신호수[D-360 ~ D-181], 1)
```
- 유효 조건: **동일 티커 · 지수 창 D-180~D-31 안에서 채널 ≥2 합류**
- 각 채널은 지수 창 내 신호 존재 시 1 카운트 (동일 채널 중복 1 로 clip)
- 촉매 이벤트일 D-day 는 §2 (H1a·FDA 승인·H5 등) 이벤트 풀에서 공급 (독립 정의)

## 3. 소문 지수 산정 (v2 · 사전 커밋)

- **지수 창**: **D-180 ~ D-31** (수익 창 D-30~D-1 배제)
- **기준선 창**: **D-360 ~ D-181** (기준선 부재 시 max(기준선, 1) 로 0 나눗셈 방지)
- **정규화**: **증가율** `= (지수창 신호수 - 기준선 신호수) / max(기준선 신호수, 1)` (초안 커밋 · z-점수 대안은 별도 세션)
- **채널별 카운트**: 채널당 지수 창 내 신호 존재 시 1 (중복 clip)
- **유효 조건**: `distinct_channels ≥ 2` (단일 채널 신호 배제 · L14)
- **상/하 절반**: 이벤트를 소문 지수 값 기준 정렬 후 상위 50% / 하위 50%

## 4. 검정 3항 (사전 커밋 · 사후 조정 금지)

### 검정 1 · 선행성
- 촉매 이벤트별 소문 지수 상/하 절반 분리
- 각 절반의 **D-30 ~ D-1 net excess** 산출 (§3-5 판정식 승계)
- **차이 (상 - 하) 의 bootstrap 95% CI 하한 > 0 → 지지**

### 검정 2 · 시차 분포
- 약물별: `첫 전문가 언급일` → `회사 발표일` → `최대 상승일` 3구간
- 두 시차의 **중앙값·사분위** 산출
- 사전 임계 없음 · 관찰 리포트 (검정 1·3 판정 보조)

### 검정 3 · "뉴스에 팔기" (v2.1 · 전/후 창 명시)
- **전반부 (소문→뉴스)**: 창 **D-30 ~ D-1** · net excess 산출
- **후반부 (뉴스이후)**: 창 **D+1 ~ D+30** · net excess 산출
- **판정**: 전반부 CI 하한 > 0 **AND** 후반부 CI 상한 ≤ 0 → "뉴스에 팔기" 지지
- **부호 부합**: 전반부 양(+) · 후반부 음(-) 또는 0 · 두 조건 모두 충족 시만 지지 (일방 조건 지지는 불충분)

## 5. 알파 임계 (사전 커밋)

- **통과**: 검정 1 CI 하한 > 0 **AND** 검정 3 후자 CI 상한 ≤ 0
- **폐기**: 검정 1 CI 하한 ≤ 0 **AND** 검정 3 불지지

## 6. 이벤트 풀 (사전 커밋 · v2.2 · WP40 · 2026-09-13 · 결과 발표일 최우선)

**Fable 인사이트 (README §0 가능성 지도 · WP36)**: FDA 승인일은 예정된 날짜 · 뉴스 아님 (원개발사도 승인 직후 하락 · LLY imm CI 전부 음수 · WP38 확인). 격언의 "뉴스" = **예상 못 한 임상 결과 발표**. 촉매 기준점을 결과 발표일로 옮긴다.

**이벤트 풀 순위 (v2.2 사전 커밋)**:

1. **1순위 · 임상 결과 발표일 (WP39)**: 8-K Item 7.01/8.01/2.02 + EX-99 보도자료 · 키워드 (topline · phase 3/2 results · pivotal · primary endpoint) · 방향 태그 (met / did not meet / failed / significant) · **예상 못 한 뉴스** · acceptance datetime 기반 D 배정 (장전=당일 · 장중/장후=다음 거래일)
2. **2순위 · FDA 승인** (PDUFA date 확정분) · **예정된 뉴스 · 비교군**
3. **3순위 · H1a (사전 공지 ADCOM · Federal Register API 공고 · WP2 실측 457건)**
4. **4순위 · H5 국내 촉매 (v2.1 확정 후 편입)** · 해외 D-day → KST 캘린더일

**검정 1·3 재정의 없이 풀만 교체 (v2.2 · 사전 커밋 유지)**:
- 검정 1 (선행성): D-30~D-1 net excess 상/하 절반 비교
- 검정 3 (뉴스에 팔기): 전 D-30~D-1 vs 후 D+1~D+30 CI 비교
- 소문 지수 산정 (D-180~D-31) 동일

**결합 금지**: H4 (소매 소셜) 이벤트는 H8 이벤트 풀에서 제외 (이중계상 방지)

## 7. 백테스트 사양 (§3-5 승계 · 30/180d → 30d 단축)

- 진입: **D+1 종가 (adj_close)** · 창 **D+1 ~ D+30**
- benchmark: XBI (참고 IWM)
- net = 왕복 1.0% · 민감도 0.5/2.0/5.0%
- bootstrap 10,000회 · seed 42 · block bootstrap 병기
- 창 단축 규약 (B99) · entry_lag ≤7d (B101) · exit_overshoot ≤15d flag

## 9. 알려진 편향·리스크

- **선택 편향**: 촉매 이벤트일 D-day 자체가 사후 시점 (accelerated review 등) 이면 순차 위반 · H1a 등 사전 공지 이벤트만 사용
- **채널 접근성 편향**: 학회 초록·EMA CHMP 등 접근 제약 시 신호 수 과소 추정 (B125 실측 결과에 따라 채널 축소 가능성)
- **KR 조회공시 편향**: 발동 시점이 회사 발표에 반응하는 경우 (순수 소문 아님) · KR-TRACK 문서에서 별도 판정
- **Form 4/13D 이중계상**: H3 은 이벤트 = filing 자체 · H8 은 이 filing 을 채널로 재사용 · H8 이벤트 풀에서 H3 이벤트 자체는 제외 (D-day 로 쓰지 말고 채널 신호로만)
