## 4. 보유·청산 사다리 v2 (사전 커밋 · 사후 조정 금지)

**최대 보유 기간**: **≤36개월** (그 이후는 재평가 · 재편입 별도 세션)

**단계 전환 사다리 (50/50)**:
1. **단계 전환 발표 직전 (전영업일 종가) · 50% 청산**: 임상 1→2상 · 2→3상 · PDUFA 확정 등 발표 D-day 이전 영업일 종가 매도 · **뉴스 전 매도 원칙 (H8 검정 3 지지 방향)**
2. **단계 전환 발표 후 종가 (D-day close) · 50% 청산**: 뉴스 공개 후 종가 매도 · 뉴스 반응 흡수

**가격 사다리 (병행 · 사전 커밋)**:
- **3배 도달 (진입가 대비) → 33% 청산** (도달일 종가)
- **10배 도달 → 33% 청산**
- **잔여 34%**: 단계 전환 사다리 완료 시 청산 (단계 전환 부재 시 36개월 만기 청산)

**D+180 무촉매 청산 삭제 (v2)**: 사용자 전략은 초기 매집 후 장기 보유 · 승수 특성 반영 위해 시간 청산 폐기

## 5. 판정 지표 v2 (사전 커밋 · 히트율 임계 삭제)

**로그 수익률 기반 (승수 특성 반영)**:
- **평균 log return**: E[log R]
- **중앙값 log return**: median[log R]
- **≥10x 도달 비율**: P(R ≥ 10)
- **≤-80% 손실 비율**: P(R ≤ 0.2)
- **95% CI 하한**: bootstrap 10,000 · seed 42 · **block bootstrap (분기 cohort 단위)** 병기

**히트율 임계 삭제 (v2)**:
- 사용자 전략은 5% 승률 + 소수 100x 로도 알파 성립 가능
- 히트율 조건은 대다수 스코어 5% 이하일 경우 알파 부재로 오판정
- 따라서 히트율 대신 로그 수익률 분포 지표 5종으로 판정

## 6. 알파 임계 (v2 · 사전 커밋 · 사후 조정 금지)

- **알파 통과**: bootstrap 로그 95% CI 하한 > 0 **AND** 로그 중앙값 > 0
- **폐기 조건**: 로그 CI 하한 ≤ 0 **AND** 로그 중앙값 ≤ 0 (양 조건 모두 미달)

## 7. 비용 v2 (사전 커밋)

- **총 왕복 1.0%** · 진입 1회 + 청산 분할 (50/50 사다리 or 3x/10x 사다리) = 매도 회수 별로 분할분 비례
- 예: 50% 분할 매도 → 매도 회 마다 0.5% × (해당 분할 비중 / 100) 비용
- **민감도 0.5% / 2.0% / 5.0%** 병기
