## 3. 설계
1. 서버: 계획 상세 응답(및 목록 한 줄용 최소 칸)에 표시 전용 `why` 추가. 응답 만들 때만 계산 · 최신 파일 읽기 · 바깥 호출 0 · 파일 수정 시각 기준 캐시(상세는 10초마다 다시 읽음) · 실패하면 `why: null` 로 끝내고 응답은 200.
2. `params_json` · APPROVAL_KEYS · `runtime_json` · `content_hash` · `revision` 에 쓰지 않는다. `drafts.decide` · 자료 읽기 입력 불변. 승인 대화상자는 `approval_values` 만.

4. 화면: 새 카드 3개(A · B · C) + 링크 + 목록 한 줄 · DESIGN.md(그림자 없음 · 반경 14/8/알약 · 17px · tabular-nums) · 375px 좌우 스크롤 없음 · 명령문 · 신호 낱말 없음.
