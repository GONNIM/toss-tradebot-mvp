## 3. 규칙 (실행 전 고정 · 결과 본 뒤 바꾸면 표본 밖 결과로만 판정)

공통 정의: σ20 = 최근 20거래일 종가 일간 수익률 표준편차 · 평균선은 종가 단순 평균 · 손익은 비용 반영 실질 평단 기준 · **미국 종목의 손익·흑자 전환은 달러 기준**으로 판정하고 원화 환산은 표시만 한다 (`HoldingSnapshot` fx_rate·purchase_amount).

### 단기 종목

| 규칙 | 조건 (그날 종가로 판정 · 다음 거래일 종가로 체결) | 규칙 계산값 |
|---|---|---|
| A 흑자 추가 | 손익 ≥ +5% · 종가 > 20일 평균 > 60일 평균 · 종가가 20일 평균 위이고 차이 ≤ 1×σ20 | 처음 수량의 1/3 추가 · 한 오름세에 2번까지 (20일 평균 < 60일 평균이 되면 횟수 초기화) · 상한 = 그 종목 처음 투입금의 +66% (㉦②) |
| A 뒤 손절 상향 (㉡②) | A 로 추가한 뒤 | 손절 기준을 합산 평단(비용 포함) 이상으로 올림 |
| B 적자 일부 매도 | 손익 < 0 · 종가 < 60일 평균 · 종가가 20일 평균에 닿음(종가 ≥ 20일 평균) | 보유 1/3 매도 |
| B1 재매수 (승인된 처음 안) | B 매도 뒤 20거래일 안에 종가 ≤ 판 값 × (1 − max(5%, 1.5×σ20)) | 판 수량 재매수 · 20거래일 지나면 재매수 안 함 |
| B2 재매수 (㉠ 대안) | B 매도 뒤 종가 > 60일 평균 2거래일 연속 또는 20일 평균 > 60일 평균 · 기한 없음 | 판 수량 재매수 · 그동안 판 돈은 현금 |
| C 손절 사실 | 종가 < 평단 × 0.85 이고 종가 < 60일 평균 (사용자 청산 계획 손절가가 있으면 그 값) | 사실 표시 |
| D 이익 보호 (㉡②) | 손익 > 0 · 최고 종가(보유 뒤) 대비 하락 ≥ max(8%, 2.5×σ20) · 종가 < 20일 평균 | 보유 전량 매도 계산값 (추적 손절) |

- 메모: σ20 은 일간 값 그대로 쓴다 (보통 종목은 B1 5% · D 8% 바닥값이 적용되고, 흔들림이 큰 종목만 넓어짐). D 수량은 추적 손절 관례대로 전량으로 고정 (PO 고정 · 사용자 보고). A 의 「0~3%」는 ㉡ 검증 권고대로 0~1σ20 로 표준화했다. C 는 변동성으로 넓히지 않는다(승인 값 유지).

### 장기 종목 (㉣②)

- 제안은 A(추가 · 2번 제한 · +66% 상한) 하나만.
- B·C·D 와 손절 상향은 제안이 아니라 **사실 표시**: 평단 대비 손익 · 20/60/120일 평균 위·아래 · 보유 뒤 최고 종가 대비 하락 · 합산 평단. 200일 평균은 토스 일봉 209개로 계산 날이 모자라 쓰지 않는다 (외부 일봉 대조 뒤 다시 검토).

### 단기 종목 흑자 전환 판단 화면 (㉤②)

- 계기: 단기 종목의 달러/원 현지 통화 손익이 비용 반영 0 을 넘은 첫 날.
- 보여 줄 사실 5가지: ① 비용·환율 반영 실질 손익 ② 추세 상태 (20/60일 평균 · D 조건까지 거리) ③ 대형·대표 기준 N/3 (아래) ④ 세금 한 줄 (규칙 문장만 · 올해 실현 손익은 자료 없음) ⑤ 백테스트 비교 「본전 매도 vs D 로 보내기」 결과 한 줄.
- 「팔라 · 장기로 하라」 문장은 쓰지 않는다. 장기로 바꾸면 장기 규칙으로 넘어간다.

| 항목 | 국내 | 미국 |

## 4. 1단계 백테스트 (화면 없음 · 배포 없음)

- 스크립트 `backend/scripts/holdings_swing_backtest.py` · 로컬 실행 · 운영 DB 는 읽기만.
- 자료: 국내 = krx_daily_candles 49종목 전부 (2024-06-10~2026-10-30 · 수정주가) · 미국 = 2026-11-08 기준 S&P 100 구성 종목 고정 목록 (파일로 저장) · yfinance 2년 · auto_adjust=False · Close 사용 (분할 반영·배당 미반영 확인 11/08 · 분할 2건 · Stock Splits 를 다시 곱하지 않음).
- 종가만 사용 (화면과 같은 조건).
- 창: 60거래일 보유 · 비겹침(시작 간격 60거래일) 주 판정 · 10일 간격은 참고. 표본 = 조건이 한 번 이상 발동한 비겹침 창 · 발동률 보고. 시장별 비겹침 표본 ≥ 200.
- 비교 기준: 그대로 들고 있기. 규칙 A 는 두 쪽 모두 같은 총투입(처음 매수금 + 추가 매수용 현금)으로 시작 · 그대로 쪽은 추가분을 현금(이자 0%). 수익률 = 끝 평가액 ÷ 총투입 − 1.
- 비용 (추정 · 첫 일에 공식 값 확인 · 연도별 적용): 국내 매도 거래세+농특세 상한 0.20% · 국내 수수료 편도 0.015% · 미국 수수료 편도 0.1% · 환전 편도 0.1% (통화가 바뀌는 거래에만) · 양도세는 회차 계산에서 빼고 한계로 적음.
- 기간 나눔: 앞 2/3 표본 안 · 뒤 1/3 표본 밖 (국내 표본 밖 약 150창 · 방향 확인만).
- **미리 등록한 비교 2건 (그 밖에 늘리지 않음):** ① B1 vs B2 (㉠③) — 표본 안에서 나은 쪽을 고르고 표본 밖에서 한 번만 판정. ② 흑자 전환 「본전 매도(다음 거래일 종가 매도) vs D 로 보내기」 (㉤②) — 「평단 아래 5% 이상 내려갔다가 평단을 회복한 창」에만 적용 · 비겹침 표본 < 100 이면 판정 없이 사실만. 3건 이상이 되면 (나) 하한을 −1%p → 0 으로 올림.
- 통과 기준 (규칙·시장마다 · 비용 뺀 뒤): (가) 평균 수익 차이(규칙 − 그대로) ≥ 0 (나) 종목 블록 부트스트랩 2,000회 90% 신뢰구간 아래 끝 > −1%p (다) 하위 5% 수익이 2%p 넘게 나빠지지 않음 (라) 표본 밖에서도 (가) 유지. 못 넘은 규칙은 화면에 안 보임.
- 물타기(낮은 값 추가 매수)는 참고 결과만 · 사용자가 다시 정할 때 씀.
- 대형주 「고점 대비 8% 하락 연 1회 이상」 빈도를 국내 49종목으로 사실 확인 (㉣ 추정 확인).
- 보고서 `docs/plans/holdings-swing/backtest-<날짜>.md` · 보유 종목 티커·수량·평단 적지 않음 · 머리에 종목 선정 편향(2026 시총 대형주) · 한 국면(2024-06~2026-10) 한계.
