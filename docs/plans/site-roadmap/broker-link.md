## 2. 목표 · 하지 않을 것 · 실패
- 목표: 종목이 보이는 자리에서 한 번 눌러 맥북 브라우저 새 탭에 그 종목의 토스증권 주문 화면이 열린다. 실주문 안전 상태와 내 증권 계좌 가는 길이 한 곳에 있다.
- 하지 않음: 주문 대신 넣기 · 계좌 로그인 연동 · 카카오페이증권 종목별 링크 (사용자는 ISA·ETF 를 앱에서 직접) · 매수·매도 권유 문장.
- 링크 주변·알림 줄에 「지금·매수·매도·추천」 류 단어 금지.
- 실패: 다른 종목이 열림 (미국 코드 오류) · 「지금 사세요」 류 문장 · 로그인 전 401 반복 · 실주문 허용 상태를 잘못 보여 줌.

## 3. 사실 (10/25 조사)
- 토스증권 웹 국내: `https://www.tossinvest.com/stocks/A{6자리}/order` (예 A005930). 계좌: `https://www.tossinvest.com/account` (200).
- 토스증권 웹 미국: 티커가 아니라 자체 코드. 사용자 예 `https://www.tossinvest.com/stocks/US19810527001/order` = `US` + 상장일 YYYYMMDD + 순번 3자리 (추정). 웹은 SPA 라 주소만으로 존재 여부를 알 수 없음 (없는 코드도 200).
- 공식 토스 Open API `GET /api/v1/stocks?symbols=AAPL,005930` (최대 200건) 의 StockInfo 에 `listDate` (KST 기준) · `isinCode` · `name` 이 있음 (openapi.json). 프로젝트 toss_client 가 이미 OAuth 로 붙어 있으나 종목 정보 메서드는 없어 새로 만든다 (use_account_header=False · 한도 STOCK 3/s 이미 매핑). listDate 날짜 기준 (KST·미국) 은 미확정 — 명세 예시 AAPL 1980-12-12 는 미국 날짜.
- 미국 코드 대조 ①: 사용자 예 `US19810527001` = 웬디스 (WEN). 회사 연혁상 1981년 5월 NYSE 상장 (ticker WEN · 2011-12-27 NASDAQ 이전) → 코드 날짜의 해·달 일치 · 일자는 서버 배치 첫 실행 때 토스 API listDate 로 대조. 상장일은 IPO 일 (1976) 이 아니라 그 거래소 상장일로 보임.
- 토큰 주의: 토스 명세 「client 당 유효한 access token 은 1 개 · 재발급 시 이전 token 즉시 무효화」 → 로컬에서 토스 API 를 부르면 서버 토큰이 끊긴다. 종목 조회는 서버 배치에서만. toss_client 는 `token-revoked` 코드를 처리하지 않음 (189행은 invalid·expired 만) → PR 2a 에서 같이 처리.
- 카카오페이증권: 웹 거래 화면 없음 (kakaopaysec.com 은 회사 소개) · 앱 전용으로 보임 · 앱 바로 열기 주소 미확인.
- 안전 (1025-01 · 앞 질의 execpage-decision-2 조건): 결론 한 줄은 live_enabled · sniper_enabled · watchlist_execute.enabled · kill_switch 네 값 · 주문 대상은 EXECUTION_BROKER (지금 미설정 = 모의) · 오늘 손익은 1025-02 전까지 숫자로 내지 않음 · /lab/execution 퇴역 시 참조 4곳 정리.
